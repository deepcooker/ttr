#### 三、Class 1 —— 离散结构参数（有限选择，不可连续优化）

#### 四、Class 2 —— 连续风险参数（TPE 主战场，窄区间硬约束）
这是 TPE 优化的核心区域，区间必须严格限定，杜绝高风险探索。

1. **网格基础间距（%）**

   - 有效区间：[0.05%, 0.12%]
   - 禁止边界：
     - ❌ < 0.05%（手续费吞噬，现金流断裂）
     - ❌ > 0.15%（无实质现金流意义，收益无法覆盖成本）

2. **单笔仓位占比**

   - 有效区间：[0.5%, 2.0%] of Total Inventory
   - 约束逻辑：TPE 易过度放大仓位追求收益，必须严格掐死，防止堆仓风险

3. **净敞口上限**

   - 有效区间：[15%, 25%]
   - 约束逻辑：超过 25% = 沦为方向赌徒，违背中性做市核心，丧失网格对冲价值

4. **WAR MODE 收缩系数**

   - 有效区间：[2.0, 3.0]
   - 约束逻辑：太小 = 风险收缩无效；太大 = 彻底脱离市场，丧失后续现金流来源

5. **持仓时间上限（分钟）**

   - 有效区间：[5, 15]
   - 约束逻辑：高频系统核心，避免长期持仓暴露趋势风险

#### 六、参数联动硬约束（最重要，防止 TPE 作弊）
单一参数合规不代表整体安全，必须通过联动约束杜绝 TPE 寻找“钻空子”的解，这是系统安全的核心保障。

🔒 **约束 1：仓位 × 网格**

- 公式：单笔仓位 × 网格层数 ≤ 10%
- 目的：防止“多层堆仓”，避免单方向仓位过度暴露，杜绝极端行情下的大幅亏损

🔒 **约束 2：网格 × 成本**

- 公式：网格间距 ≥ 2 × 实际单边成本
- 说明：实际单边成本包含手续费、滑点、延迟带来的隐性成本
- 目的：保证每一笔网格成交具备基础盈利空间，避免手续费吞噬现金流

🔒 **约束 3：净敞口 × WAR MODE**

- 公式：WAR MODE 净敞口上限 = 常态净敞口上限 × 0.5
- 目的：保证 WAR MODE 具备实质风险收缩效果，不是形式上的状态切换

🔒 **约束 4：返佣依赖度**

- 公式：Rebate PnL / Total PnL ≤ 70%
- 目的：避免系统过度依赖返佣存活，防止交易所规则变动导致的突发性死亡

#### 一、先对齐核心认知：回测的核心目的（非收益计算）
本回测框架不用于测算盈利水平，仅用于解答3个生死问题：

1. 系统是否存在结构性死亡路径
2. 现金流是否会在返佣T+n到账前断裂

**关键结论**  
👉 回测引擎 ≠ 策略引擎

#### 五、Strategy FSM（状态机，非策略逻辑）
**核心状态定义**

1. NORMAL：常态运行，标准网格参数
2. WAR_MODE：风险紧急收缩，网格参数调整
3. COOLDOWN：WAR模式退出后，冷却缓冲
4. DEAD：本组参数淘汰，终止回测

**状态转换事件（触发条件→状态变更）**

| 触发事件                  | 状态转换                  |
|---------------------------|---------------------------|
| 连续单边成交              | NORMAL → WAR_MODE         |
| ATR爆发（突破历史阈值）   | NORMAL → WAR_MODE         |
| 手续费吞噬（Gross PnL < Fees） | NORMAL → WAR_MODE     |
| 风险指标回归安全区间      | WAR_MODE → COOLDOWN       |
| 冷却时间耗尽              | COOLDOWN → NORMAL         |
| 爆仓/现金流断裂/MaxDD超限 | ANY → DEAD                |

**关键结论**  
👉 DEAD状态即本组参数淘汰，无挽回空间

#### 六、Quoting Engine（回测版网格生成，简化但致命）
**常态网格生成逻辑**

```plaintext
anchor = VWAP / mid proxy（价格锚点）
for i in grid_levels（网格层数）:
    buy_price  = anchor * (1 - spacing * i)（买单价格）
    sell_price = anchor * (1 + spacing * i)（卖单价格）
```

**WAR MODE 核心行为调整（收缩风险）**

1. 网格间距：spacing × 风险系数（如2.5倍）
2. 仓位限制：禁止逆趋势侧新增订单
3. 网格层数：减少grid_levels，降低暴露

#### 七、成交模型（重点：对策略不友好，无乐观假设）
**Maker 单（挂单成交）**

1. 成交触发：只有当价格路径穿越挂单价时，才触发成交
2. 成交价：严格等于挂单价，不幻想更优价格
3. 无部分成交：要么全额成交，要么不成交

**Taker 单（对冲成交）**

1. 成交价：当前价格路径的极值（高/低），对策略最不利
2. 额外惩罚：叠加固定滑点（如0.05%），模拟实盘冲击
3. 优先成交：对冲单高于Maker单，保证风险快速释放

#### 八、Inventory Engine（核心测试对象，仓位与重心管理）
**维护的核心数据**

1. long_size：多头持仓量
2. short_size：空头持仓量
3. net_exposure：净敞口（long_size - short_size）
4. inventory_center：仓位重心
5. holding_time：持仓时间

**核心更新逻辑**

1. 每笔成交后，实时更新多空持仓量与持仓时间
2. 同步计算仓位重心偏差：|当前价格 - inventory_center|
3. 当偏差突破阈值时，向Risk Engine上报风险信号

#### 九、Cashflow Engine（返佣 T+n 核心，现金流生死线）
**每笔成交的资金变动逻辑**

1. 手续费扣减：fee += 成交名义价值 × 手续费率（实时扣减现金）
2. 待返佣登记：rebate_pending += 成交名义价值 × 返佣率（记录成交日期）
3. 保证金更新：同步更新占用保证金（margin_used）

**返佣到账逻辑（T+n 延迟）**

```plaintext
每一天收盘后：
    for 所有待返佣记录:
        if 当前日期 >= 成交日期 + n:
            现金 += 该笔待返佣金额
            移除该条待返佣记录
```

**现金流生死线（任一时刻校验）**

```plaintext
free_margin = 权益（equity） - 占用保证金（margin_used）
```

❗ **关键规则**：若 free_margin ≤ 0 → 直接判定DEAD，终止回测

#### 十、Risk Engine（唯一裁判，硬死亡条件）
**硬死亡条件（任一触发即判定DEAD）**

1. 爆仓（权益 < 爆仓线）
2. 保证金断裂（free_margin ≤ 0）
3. 最大回撤超限（MaxDD > 预设阈值，如15%）
4. 连续WAR MODE超限（如月度触发超5次）
5. 仓位重心偏差超限（如≥0.6%，且无法强制处理）

```python
        self.cooldown_left = 0

            self.state = State.WAR

        elif event == "EXIT_WAR":

            self.state = State.DEAD
```

#### 八、Cashflow Engine（反佣 T+n 命门）

```python
class Cashflow:
    def init(self, fee_rate, rebate_rate, delay):
        self.cash = 1.0
        self.margin = 0.0
        self.fee_rate = fee_rate
        self.rebate_rate = rebate_rate
        self.delay = delay
        self.pending = []

    def on_trade(self, notional, day):
        fee = notional * self.fee_rate
        rebate = notional * self.rebate_rate

        self.cash -= fee
        self.pending.append((day + self.delay, rebate))

    def on_day_end(self, day):
        for d, r in list(self.pending):
            if d <= day:
                self.cash += r
                self.pending.remove((d, r))

    def free_margin(self):
        return self.cash - self.margin
```

#### 九、Risk Engine（唯一生死裁判）

```python
class RiskEngine:
    def init(self, max_dd):
        self.max_dd = max_dd
        self.peak = 1.0

    def check(self, equity):
        self.peak = max(self.peak, equity)
        dd = 1 - equity / self.peak

        if dd > self.max_dd:
            return "DEAD"
        return None
```

```python
def run_backtest(bars, params):

        grid = generate_grid(
            anchor,
            params["spacing"],
            params["levels"],
            fsm.state

        fills = process_fills(grid, path, params["size"])

            inv.update_on_fill(side, size, price)
            cash.on_trade(size * price, day)

        cash.on_day_end(day)

        equity = cash.cash  # 简化
        verdict = risk.check(equity)

        if verdict == "DEAD" or cash.free_margin() <= 0:
            fsm.on_event("DEAD")
            return False

        day += 1

    return True
```

#### 一、Inventory & Risk 数学约束化
**核心逻辑**：连续约束 + 必死判定，非 if-else 逻辑，是系统“灵魂”分水岭

1. **核心状态变量（连续）**  
   仅承认6个真实风险变量：

   - $$E_t = \text{Equity}$$
   - $$M_t = \text{Used Margin}$$
   - $$F_t = \text{Free Margin} = E_t - M_t$$
   - $$N_t = \text{Net Exposure / Equity}$$
   - $$C_t = \text{Inventory Center Drift}$$
   - $$H_t = \text{Inventory Holding Time}$$

2. **净敞口约束（方向性原罪）**

   - 数学定义：$$|N_t| \le N_{\text{max}}$$
     - 常态：$$N_{\text{max}} = 0.2$$
     - WAR MODE：$$N_{\text{max}} = 0.1$$
   - 连续惩罚：$$\text{Penalty}_N = \exp\left(\frac{|N_t|}{N_{\text{max}}} - 1\right)$$
   - 要求：TPE/回测必须体现该惩罚

3. **仓位重心漂移（网格真实死亡路径）**

   - 定义：$$C_t = \frac{|P_t - \text{InventoryCenter}|}{P_t}$$
   - 约束：
     - 软约束：$$C_t \le 0.3\%$$
     - 强制处理：$$C_t \ge 0.6\%$$
   - 数学处理：$$\text{Penalty}_C = \max(0, C_t - 0.3\%)^2$$

4. **持仓时间约束（高频系统易忽略）**

   - 约束：$H_t \le H_{\text{max}}$，$$H_{\text{max}} \in [5,15]\ \text{min}$$
   - 超时处理：主动减仓/市价对冲，允许亏损
   - 核心：时间是风险，非变量

5. **现金流硬约束（返佣 T+n 杀手）**

   - 生死线：$$F_t > F_{\text{min}}$$
   - 其中：$$F_{\text{min}} = \alpha \times \text{Max(Expected Fee Outflow during T+n)}$$
     - $$\alpha \ge 1.5$$（保守值）
   - 触发即 DEAD

6. **回撤约束（非指标）**

   - 定义：$$DD_t = 1 - \frac{E_t}{\max(E_0 \dots E_t)}$$
   - 生死规则：$$DD_t \ge 15\% \to \text{DEAD}$$
   - 注意：不允许“慢慢恢复”，回撤是结构失败信号

7. **最终 Risk Score（TPE/压测用）**

   - $$\text{RiskScore}_t = w1 \cdot \text{Penalty}_N + w2 \cdot \text{Penalty}_C + w3 \cdot \text{Penalty}_H + w4 \cdot DD_t$$
   - 触发条件：任意时刻 $$\text{RiskScore}_t$$ 爆表 = 系统有结构性漏洞
